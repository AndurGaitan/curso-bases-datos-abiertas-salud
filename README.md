# Curso de Posgrado: Bases de Datos Abiertas en Salud

Repositorio oficial de scripts y recursos prácticos del **Curso de Posgrado Bases de Datos Abiertas en Salud**.

El curso está dirigido a profesionales de la salud interesados en adquirir herramientas iniciales para trabajar con bases de datos relacionales, realizar consultas mediante SQL y construir indicadores aplicados al análisis de datos sanitarios.

## Funciones del repositorio

Este repositorio tiene como objetivos:

- Centralizar los scripts utilizados durante el curso.
- Organizar las consultas SQL por módulo y nivel de complejidad.
- Compartir versiones actualizadas y corregidas de los scripts.
- Promover consultas claras, documentadas y reproducibles.
- Servir como base para la construcción de datasets e indicadores de salud.

## Herramientas utilizadas

Durante el curso se trabajará principalmente con:

- PostgreSQL
- pgAdmin
- SQL
- MIMIC-IV Demo
- Power BI Desktop

## Recomendaciones de uso

Se recomienda seguir el orden de los módulos, leer los comentarios incluidos en cada script y validar los resultados obtenidos antes de continuar con una nueva consulta.

Los scripts tienen fines educativos y podrán ser actualizados durante el desarrollo del curso.

## Uso responsable

No deben incorporarse datos clínicos identificables, contraseñas, credenciales de acceso ni información institucional sensible.

Las actividades se realizarán utilizando bases de datos abiertas, desidentificadas o preparadas específicamente para docencia.

## Consultas

Las dudas sobre los scripts, ejercicios o contenidos deberán realizarse a través de los canales oficiales del campus virtual del curso.
